日期：2026-10-11。修复分支：`codex/issue-92-plugin-readability`，基于最新 `origin/main`（`7b23b3a`）。原工作区未提交文件未改动。

## 实现与边界

共享 `readability.js` 为 DSH Web / 官方 Desktop 的插件标题、各分组、卡片、详情、配置和异步状态铺完全不透明的局部底板；页面外框和组间间隙保留壁纸。说明文字及计数局部采用宿主 secondary 标签色。沿用原有保护开关、偏好同步和注入协议，无新增依赖。

保留宿主圆角和布局。审查发现：为无内边距的分组强加圆角，会使首字背后的底板被裁切；已删除这条规则，并用白／黑壁纸下标题截图完全一致的回归验证。测试阶段属性须位于 `#root` 后代，已增加真实选择器匹配断言。

## 真实应用

使用官方 DSH Desktop 0.2.0-rc.2，以及其自带同版本 CLI 启动的真实 Web。全局旧 Web CLI 0.1.0-rc.6 缺少新版独立插件页／注入机制，未作为本次新版契约验收依据。

使用隔离 profile 和背景目录加载独立候选，并与 tarball 解包文件逐字节核对。Web 与 Desktop 的背景目录分别隔离；首次同时验收曾竞争锁，持锁进程 35232 已结束，分离后背景应用成功。未修改注入器的锁机制。

Web 在两种主题下验证标题、官方组和已安装组底色分别为 `rgb(255,255,255)` / `rgb(53,54,56)`；插件详情和配置同样为实色。官方 Desktop 验收深浅主题列表、终端详情／配置、返回后的新挂载列表和安装弹窗，保留外框背景及负边距卡片。加载、空、错误／重试等状态用真实结构 fixture 验证，未人为破坏真实应用制造错误。拖动属性和命中区域由回归检查；当前官方版本现场拖动插件页标题文字表现为选中文字，未证明它能移动窗口，此项保留宿主现有行为，不宣称修复窗口拖动。
